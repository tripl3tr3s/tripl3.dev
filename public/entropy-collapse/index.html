The derivation this is running

Three tokens, logits x₁ > x₂ ≫ x₃, probabilities pᵢ from softmax. Token 3 is sampled and its trajectory earns a negative advantage Â. The gradient of log p₃ with respect to the logits:

∇ log p₃ = [ -p₁, -p₂, p₁+p₂ ]

The policy-gradient update is proportional to Â times that gradient. Since Â < 0:

Δx₁ ∝ |Â|·p₁    Δx₂ ∝ |Â|·p₂    Δx₃ ∝ -|Â|·(p₁+p₂)

x₁ and x₂ both increase, but each by an amount proportional to its own current probability. Since p₁ > p₂, x₁ gains more than x₂ in absolute terms: the gap widens. Punishing a rare token is not a uniform reallocation, it is a proportional one, so whichever token was already ahead pulls further ahead. Run that over thousands of steps and the distribution keeps sharpening: entropy collapse.

Top-p sampling breaks the loop by excluding thin, off-distribution tokens like x₃ from the sampleable set entirely. If x₃ can never be drawn, it can never generate this update. The one wrinkle: doing this naively creates a new mismatch between what the trainer computes over the full vocabulary and what the sampler actually drew from, fixed by replaying the same kept-set mask at training time so both sides agree on the same renormalized distribution.
